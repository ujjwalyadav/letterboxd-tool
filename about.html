How it works

Your data stays understandable.

The site separates your Letterboxd activity from external movie metadata, keeps API credentials out of the browser, and rebuilds automatically when you update your CSV exports.

Update workflow

You only need to replace your Letterboxd CSV files. GitHub Actions does the metadata work and publishes the new static site.

  1. Replace your exports.
    Put updated diary.csv, ratings.csv, watched.csv, and watchlist.csv into the data/ folder.
  2. Push to GitHub.
    The included workflow runs automatically whenever those files or the enrichment code change.
  3. Enrichment runs privately.
    The workflow reads your TMDB_API_TOKEN from GitHub Actions Secrets. The token is never written into the website files.
  4. The site republishes.
    The browser receives one generated catalog JSON containing your merged Letterboxd activity plus safe public movie metadata.

Data model

The project intentionally preserves where each field came from.

Letterboxd export

Your activity

Personal rating, diary entries, rewatch flags, tags, watched status, watchlist status, and the dates included in your export remain your authoritative personal data.

TMDB

Film metadata

Runtime, genres, production countries, languages, directors, writers, cast, keywords, posters, backdrops, TMDB rating/vote count, popularity and other movie metadata are fetched during the build.

Optional

Letterboxd community stats

The template data/letterboxd_community.csv supports average rating, watches and likes if you obtain them from an authorized/manual source. The project does not scrape Letterboxd pages.

Important Letterboxd limitation

Your own ratings are fully supported because they are in the export. Community-wide Letterboxd averages/watch counts are different.

Letterboxd's official API is currently request-only, and its API-access page says it is not granting access for personal/private projects or data-analysis, visualization and recommendation projects. For that reason this project does not depend on unofficial scraping. Your personal Letterboxd ratings remain available, while community-wide fields are optional through letterboxd_community.csv.

Privacy

Think about what you are publishing before you make the repository or Pages site public.

Your Letterboxd export can include viewing dates and personal tags. The deployed Pages artifact does not include the raw CSV files, but the generated catalog contains the personal fields needed by the website. Also remember that if your GitHub repository itself is public, files committed to data/ are publicly readable from the repository even if they are not part of the Pages artifact.

If any tags or viewing information are private, remove them before committing or use a repository/hosting setup whose access model fits your needs.
